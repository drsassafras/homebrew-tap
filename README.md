# drsassafras/tap

Homebrew formulae by drsassafras.

    brew tap drsassafras/tap
    brew trust drsassafras/tap
    brew install sac

Homebrew 7 asks you to trust a third-party tap once before it installs from it.

| Formula | What it is |
|---|---|
| `sac` | [Security Audit Coverage](https://github.com/drsassafras/security-audit-coverage): track which code a security audit has read and what it found |
